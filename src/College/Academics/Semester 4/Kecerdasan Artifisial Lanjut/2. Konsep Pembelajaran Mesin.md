# Definisi
- Teknik yang memungkinkan komputer untuk *belajar* dari data tanpa harus diprogram secara eksplisit
- Cabang dari AI
- Bertujuan untuk mempelajari pola data untuk melakukan prediksi terhadap data yang belum pernah dipelajari
# Tahapan Pembelajaran
1. Penyimpanan data, menyimpan data yang akan dipelajari
2. Abstraksi, proses pengubahan data menjadi representasi dan konsep yang lebih luas
3. Generalisasi, mengubah representasi data menjadi pengetahuan
4. Evaluasi, proses pengukuran proses pembelajaran
# Metode Pembelajaran Mesin
## Supervised Learning
- Belajar dari label atau kategori 
## Unsupervised Learning
- Tanpa menggunakan contoh
- Untuk pengelompokan data
## Reinforcement Learning
- Diberi hadiah atau hukuman
# Tipe Pembelajaran Mesin
## Klasifikasi
- Prediksi label/kelas
- Kelas/label: kategori yang nilainya sudah ditentukan
- Prosesnya dengan mempelajari sekumpulan data yang telah diketahui
- Bertujuan untuk melabeli data baru yang belum ada kelasnya
- Contoh supervised learning
## Regresi
- Mirip dengan klasifikasi namun labelnya berupa angka
- Bertujuan untuk memperkirakan nilai suatu variabel
- Contoh supervised learning
## Clustering
- Tidak memerlukan label
- Bertujuan untuk mengelompokkan data
- Data yang mirip akan dikelompokkan pada cluster yang sama
