# Variabel
## Deklarasi
```sql
DECLARE @name VARCHAR(225) = 'hohoho';
DECLARE @email VARCHAR(255);
```
## Pengisian
```sql
SET @name = 'gacor';
SET @name = name FROM users WHERE password='hihihi';
```
# Print
```sql
PRINT 'Nama: ' + @name
```
# Casting
```sql
PRINT CAST(@nama AS VARCHAR(69))
```
# Percabangan
## If Else
```sql
IF @nama = 'hohoho'
BEGIN
	PRINT 'hihihi'
END
ELSE IF @nama = 'gacor'
BEGIN
	PRINT 'anjay'
END
ELSE 
	PRINT 'lah'
```
## Switch Case
```sql
SELECT name, gender_name =
	CASE
		WHEN gender = 'M' THEN 'Male'
		WHEN gender = 'L' THEN 'Ladies'
	END
FROM users;
```
# Iteration
## While
```sql
DECLARE @idx INT = 1;
WHILE (@idx > 0)
BEGIN
	IF (@idx = 1) 
	BEGIN
		CONTINUE
	END
	ELSE IF (@idx = 2)
	BEGIN
		BREAK
	END
	
	SET @idx = @idx - 1;
END
```
# Stored Procedure
- SQL Server ada system stored procedure yang sifatnya global, ditandai dengan awalan `sp_`
## Pembuatan
```sql
CREATE PROCEDURE HiNama
	-- Paramater, bersifat opsional
	@name VARCHAR(255),
	-- Output
	@id VARCHAR(255) OUTPUT
AS
	PRINT 'Hello ' + @name
	SELECT @id = id
	FROM users
	WHERE name ILIKE '%@name%'
```
## Pemanggilan
```sql
DECLARE @id VARCHAR(255);
EXECUTE PrintNama 'Dansih', @id OUTPUT
```
# User Defined Function
- Digunakan untuk mengembalikan suatu nilai seperti fungsi
- Dapat dipanggil di dalam klausa `SELECT, WHERE, HAVING`, pada DML `UPDATE, INSERT, DELETE` sedangkan SP tidak bisa
- Dapat digunakan untuk mendefinisikan kolom dan `CHECK` constraint
- Dapat mengembalikan scalar (nilai tunggal) atau *result-set/table* (beberapa baris)
```sql
CREATE FUNCTION GetDayName
	(@day VARCHAR(1))
RETURNS VARCHAR(10)
AS
BEGIN
	DECLARE @day_name VARCHAR(10)
	SET @day_name =
		CASE
		WHEN @day = 'M' THEN 'Monday'
		END
	RETURN @name
END;

SELECT dbo.GetDayName('M')
```
