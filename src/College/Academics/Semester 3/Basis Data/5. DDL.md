# Tipe Data
## String
- `CHAR(N)`: panjang tetap, maksimal `N` karakter
- `VARCHAR(N)`: panjang tidak tetap, maksimal `N` karakter
- `TEXT`: panjang tidak tetap
- `NCHAR`: Unicode panjang tetap
- `NVARCHAR`: Unicode panjang tidak tetap
- `NTEXT`: Unicode panjang tidak tetap hingga 2GB
- `BIT`: 0, 1, atau NULL
- `BINARY(N)`: biner dengan panjang tetap, maksimal `N` karakter
- `VARBINARY(N)`: biner dengan panjang tidak tetap, maksimal `N` karakter
- `IMAGE`: biner dengan panjang tidak tetap untuk menyimpan image
## Angka
- `TINYINT`: bulat, 0-255 (8bit)
- `SMALLINT`: bulat 16bit
- `INT`: bulat 32 bit
- `BIGINT`: bulat 64 bit
- `DECIMAL(P, S)`: desimal 5-17 bytes (tergantung precision). P: presisi, jumlah total digit yang disimpan. S: skala, jumlah digit setelah titik desimal.
- `FLOAT`: desimal 4 bytes (approx.)
- `REAL`: desimal 8 bytes (approx.)
- `MONEY`: uang 8 bytes
- `SMALLMONEY`: uang 4 bytes
## Tanggal/Waktu
- `DATETIME`: 1 Jan 1753 - 31 Des 9999. Akurasi 3,33 millidetik
- `DATETIME2`: 1 Jan 0001 - 31 Des 9999. Akurasi 100 nanodetik
- `SMALLDATETIME`: 1 Jan 1900 - 31 Des 9999. Akurasi 1 menit
- `DATE`: 1 Jan 1753 - 31 Des 9999. Tanpa waktu
- `DATETIMEOFFSET`: Sama seperti `DATETIME2` namun hanya menyimpan offset zona waktu
- `TIME`: Tanpa tanggal. Akurasi 100 nanodetik
- `TIMESTAMP`: Angka unik yang diperbarui tiap kali baris record dibuat/dimodifikasi berdasarkan internal clock
# Create
```sql
CREATE TABLE users (
	id SMALLINT NOT NULL PRIMARY KEY IDENTITY (1, 2),
	name VARCHAR(255) NOT NULL,
	device_id VARCHAR(20) NOT NULL FOREIGN KEY REFERENCES devices(id),
	role VARCHAR(30) DEFAULT 'user' CHECK (role IN ('user', 'admin')),
	CONSTRAINT pk_id PRIMARY KEY (id),
)
```

# Update
```sql
ALTER TABLE users
ADD email VARCHAR(30) NOT NULL UNIQUE;

ALTER TABLE users
ALTER COLUMN role VARCHAR(20) DEFAULT 'user';

ALTER TABLE users
DROP COLUMN name;

ALTER TABLE users;
ADD CONSTRAINT pk_id PRIMARY KEY (id, email)
```
# Delete
```sql
DROP TABLE users
```
