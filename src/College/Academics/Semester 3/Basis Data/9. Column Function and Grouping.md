# Fungsi Group
- Operasi pada dua atau lebih baris data dan memberikan satu hasil per group
- `AVG`, `COUNT`, `MAX`, `MIN`, `SUM`
## Count
- Menghasilkan nilai jumlah baris dari sekelompok data
```sql
SELECT COUNT(*) AS total_users from users;
```
## AVG
- Menghasilkan nilai rata-rata sekelompok nilai dari sebuah field numerik
```sql
SELECT AVG(mark) AS avg_mark
FROM submissions 
WHERE assignment_id='sample_id';
```
## SUM
- Menghasilkan nilai total jumlah sekelompok nilai dari sebuah kolom
```sql
SELECT SUM(mark) AS sum_mark
FROM submissions
WHERE assignment_id='sample_id';
```
## MIN
- Menghasilkan nilai terendah dari sekelompok data dalam sebuah kolom
```sql
SELECT MIN(mark) AS sum_mark
FROM submissions
WHERE assignment_id='sample_id';
```
## MAX
- Menghasilkan nilai tertinggi dari sekelompok data dalam kolom
```sql
SELECT MAX(mark) AS sum_mark
FROM submissions
WHERE assignment_id='sample_id';
```
# Group
- Mengelompokkan beberapa data pada perintah `SELECT`
```sql
SELECT cluster, COUNT(*) AS total_per_cluster
FROM users
GROUP BY cluster
```
# Klausa HAVING
- Berkaitan dengan `GROUP BY` dan AGREGASI
- Digunakan untuk menentukan kondisi tertentu pada `GROUP BY` dan kondisi tersebut berkaitan denga fungsi agregasi
- Ini mirip dengan `WHERE`
- Digunakan karena `WHERE` tidak dapat digunakan dalam fungsi agregasi
```sql
SELECT cluster, COUNT(*) AS total_per_cluster
FROM users;
GROUP BY cluster
HAVING COUNT(*) < 11
```
## Fungsi Tanggal
- Mengambil sebagian data dari kolom bertipe DATE dan TIMESTAMP
```sql
SELECT YEAR(CURRENT_TIMESTAMP)
SELECT YEAR(GETDATE())
SELECT MONTH(GETDATE())
SELECT DAY(GETDATE())
```
