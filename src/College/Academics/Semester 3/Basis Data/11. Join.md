i# Join
- Buat menggabungkan tabel
## Inner Join
### Equi-Join
- Sama dengan *Cartesian product*
```sql
SELECT student.name, department.dept_name
FROM student, department
WHERE student.dept_name=department.dept_name
```
### Join On
```sql
SELECT student.name, department.dept_name
FROM student JOIN department
ON student.dept_name=department.dept_name
WHERE department.dept_name='Accounting';
```
### Cross Join
```sql
SELECT *
FROM student, department
```
## Outer Join
- Tabel pertama pada klausa FROM: **KIRI**
- Tabel selain itu: **KANAN**

### Left
- Hasil akhir merupakan union dari hasil akhir equi-join, termasuk beberapa baris di tabel **KIRI** yang tidak cocok
```sql
SELECT *
FROM course LEFT OUTER JOIN prereq
ON course.course_id=prereq.course_id
```
![[Pasted image 20241130213015.png]]
### Right
- Termasuk beberapa baris dari tabel **KANAN** yang tidak cocok
```sql
SELECT *
FROM course RIGHT OUTER JOIN prereq
ON course.course_id=prereq.course_id
```
![[Pasted image 20241130213023.png]]
### Full
- Termasuk beberapa baris dari tabel **KANAN** dan **KIRI** yang tidak cocok
```sql
SELECT *
FROM course FULL OUTER JOIN prereq
ON course.course_id=prereq.course_id
```
