# Perbandingan
- =, <>, !=, >, >=, <=, <=
# Logika
- `ALL`: jika semua himpunan pembanding bernilai TRUE
- `SOME`: jika beberapa dari himpunan pembanding bernilai TRUE
- `ANY`: jika salah satu dari himpunan pembanding bernilai TRUE
- `AND`: jika kedua ekspresi Boolean bernilai TRUE
- `OR`: jika satu ekspresi Boolean bernilai TRUE
- `NOT`: kebalikan dari operator Boolean
- `BETWEEN`: jika nilai berada di antara suatu rentang (Numerik)
- `EXISTS`: subquery menghasilkan baris record 
	- `WHERE year BETWEEN 2004 AND 2017`
- `IN`: operand sama dengan salah satu dari daftar ekspresi
	- `WHERE year IN (2005, 2006)`
- `LIKE`: jika sesuai dengan pola tertentu
	- `%`: any string of zero or more char
		- `WHERE title LIKE '%computer'`: find all books titles with the word 'computer' anywhere in the book title
	- `_` : any single char
		- `WHERE name LIKE 'Ri__'`: finds all four-letter first names that start with Ri (Rian, Riri)
	- `[]`: any single char within the specified range (a-f) or (abc)
		- `WHERE name LIKE 'Ria[a-c]'`: Riaa, Riab, Riac
	- `[^]`: any single char not within the specified range (^a-f) or (^abc)
		- `WHERE name LIKE 'Ria[a-c]'`: Riad, Rian, Rial
# Predicate
- Mengevaluasi hasil berupa TRUE, FALSE, atau UNKNOWN
- Digunakan dalam kondisi pencarian pada klausa WHERE dan HAVING, kondisi join pada klausa FROM, dan konstruksi lainnya yang memerlukan nilai Boolean
- `CONTAINTS`: pencarian full text atau indeks full text
- `IS NULL`: bernilai null
- `IS NOT NULL`: bernilai tidak null
# Fungsi
## Karakter/String
- `LEN`: Menghitung panjang string (tanpa spasi akhir).
- `LEFT`: Mengambil sejumlah karakter dari awal string.
- `RIGHT`: Mengambil sejumlah karakter dari akhir string.
- `SUBSTRING`: Mengambil sebagian string berdasarkan posisi dan panjang.
- `CHARINDEX`: Menemukan posisi substring dalam string.
- `REPLACE`: Mengganti substring dengan string lain.
- `UPPER`: Mengubah string menjadi huruf kapital.
- `LOWER`: Mengubah string menjadi huruf kecil.
- `LTRIM`: Menghapus spasi di awal string.
- `RTRIM`: Menghapus spasi di akhir string.
- `CONCAT`: Menggabungkan dua atau lebih string.
- `FORMAT`: Memformat string berdasarkan pola tertentu.
## Bilangan
- `ABS`: Mengembalikan nilai absolut dari bilangan.
- `ACOS,ASIN,ATAN,COS,SIN,TAN,COT`: ya gt
- `CEILING`: Membulatkan angka ke atas (ke bilangan bulat terdekat).
- `FLOOR`: Membulatkan angka ke bawah (ke bilangan bulat terdekat).
- `ROUND`: Membulatkan angka ke sejumlah digit tertentu.
- `POWER`: Menghitung pangkat bilangan.
- `SQRT`: Menghitung akar kuadrat bilangan.
- `LOG`: Mengembalikan logaritma natural (basis e).
- `LOG10`: Mengembalikan logaritma basis 10.
- `RAND`: Menghasilkan angka acak.
- `SIGN`: Mengembalikan tanda bilangan (-1, 0, 1).
## Tanggal
- `GETDATE()` dan  `CURRENT_TIMESTAMP`: Mengembalikan tanggal dan waktu saat ini.
- `GETUTCDATE()`: Mengembalikan tanggal dan waktu saat ini dengan format UTC.
- `DATEDIFF(datepart, startdate, enddate)`: Menghitung selisih antara dua tanggal.
- `DATENAME(datepart, date)`: Mengembalikan nama bagian tertentu dari tanggal (seperti hari, bulan).
- `DATEPART(datepart, date)`: Mengembalikan angka bagian tertentu dari tanggal (seperti hari, bulan).
## Coalesce
- Menampilkan suatu nilai default yang ditentukan apabila berisi null
- Tibuatkan dak akan mengubah nilai NULL yang tersimpan
- Tidak berpengaruh apabila isinya bukan NULL
