# Definisi
- Metode klasifikasi sederhana berdasarkan Teorema Bayes ($P(A|B)=\frac{P(B|A)P(A)}{P(B)}$)
- Penentuan kelas dari data uji $d$ ditentukan berdasarkan nilai posterior yang didapatkan distribusi data per kelas dan distribusi kelas pada data latih
- Kelas dari data uji $d$ diperoleh dari nilai probabilitas posterior terbesar
$$
C(d)=\arg\max_c P(c|d)
$$
# Klasifikasi Naive Bayes
- Formula Naive Bayes untuk klasifikasi cukup
$$
P(c|d)=P(c)\times P(d|c)
$$
- $P(c|d)$: posterior atau peluang kelas $c$ diberikan data $d$
- $P(c)$: prior atau peluang awal munculnya kategori $c$
- $P(d|c)$: likelihood atau conditional probability
# Prior Probability
$$
P(c)=\frac{Nc}{N}
$$
- $Nc$: banyak data pada data latih yang masuk pada kategori $c$
- $N$: banyak data pada data latih
# Conditional Probability
- Data $d$ yang akan diklasifikasikan terdiri dari beberapa fitur $w$
- Probabilitas masing-masing fitur $P(w|c)$ diasumsikan independen (alasan disebut Naive)
$$
P(d|c)=P(w_1,w_2,...,w_n|c)=P(w_1|c)\times P(w_2|c)\times ... \times P(w_n|c)=\Pi_{w\in d}P(w|c)
$$
- Untuk menghitung conditional probability, bisa menggunakan salah satu dari model berikut:
	- Bernoulli Model
	- Multinomial Model
	-  Gaussian Model
# Tahapan Klasifikasi
## Training
- Input data latih
- Menghitung prior masing-masing kategori
- Menentukan fitur berdasarkan fitur unik pada data latih
- Menghitung conditional probability per fitur per kategori
- Output model (nilai prior dan conditional probability)
## Testing
- Input model dan data uji
- Hitung posterior untuk masing-masing kategori dan menentukan kategori dengan nilai posterior terbesar
- Output kategori untuk masing-masing data uji
