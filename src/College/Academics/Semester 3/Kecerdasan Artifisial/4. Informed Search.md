# Informed Search
- Sinonim Heuristic Search
- Memerlukan pengetahuan yang spesifik pada permasalahan yang dihadapi disamping dari definisi masalahnya itu sendiri
	- Jarak untuk mencapai goal
	- Tahapan untuk mencapai goal
	- Cost dari jalur
- Digunakan untuk mendapatkan goal state dengan cost yang rendah
- Dapat memperkirakan seberapa dekat current state ke goal
- Tidak selalu menghasilkan solusi terbaik namun dapat memberikan jaminan untuk mendapatkan solusi yang cukup baik
- Heuristic Function
	- Direpresentasikan dengan $h(n)$
	- Menghitung jalur optimal di antara pasangan state
	- Hasil nya selalu positif
	- Persamaan: $h(n) \leq h*(n)$
		- $h(n)$ : heuristic cost
		- $h * (n)$ : perkiraan cost
# Best-First Search
- Idenya adalah menggunakan fungsi evaluasi $f(n)$ untuk setiap node
- Implementasinya adalah mengurutkan node di garis depan berdasarkan urutan menurunnya keinginan
## A* Search
- Idenya adalah menghindari ekspansi jalur dengan cost tinggi
- Fungsi evaluasi: $f(n) = g(n) + h(n)$
	- $g(n) =$ cost sejauh ini untuk mencapai $n$
	- $h(n)=$ perkiraan cost dari $n$ ke goal
	- $f(n)=$ perkiraan total biaya jalur melalui $n$ menuju goal
- Time Complexity = O(log n)

# Ringkasan
- Fungsi heuristik memperkirakan biaya jalur terpendek
- Heuristik yang baik dapat secara drastis mengurangi biaya pencarian
- Pencarian Greedy Best-First memperluas $h$ terendah
	- Tidak lengkap dan tidak selalu optimal
- Pencarian A* memperluas $g+h$ terendah
	- Lengkap dan optimal
	- Efisien hingga tie-break
