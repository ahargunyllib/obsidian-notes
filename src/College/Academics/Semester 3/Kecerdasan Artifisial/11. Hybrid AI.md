# Bagging
- Teknik Ensemble - Bagging (Bootstrap Aggregating)
- Mengurangi variansi dengan menggabungkan prediksi dari beberapa model independen
$$
f(x)=\frac{1}{B}\sum^B_{b=1}f_b(x)
$$
- $f_b(x)$: model individu
- $B$: jumlah model
#  Boosting
- Teknik yang menggabungkan model-model lemah untuk membentuk model yang kaut
- Setiap model lemah diperkuat dengan mempelajari kesalahan dari model sebelumnya
- Bertujuan
	- Memperbaiki kesalahan dari model sebelumnya
	- Membentuk model yang lebih akurat dengan menggabungkan model lemah
	- Meningkatkan akurasi tanpa overfitting
- Formulasi Umum
	- Misal data pelatihan $D={(x_1,y_1),(x_2,y_2),...,(x_n,y_n)}$
	- Model akhir $F(x)$ dibentuk sebagai kombinasi dari beberapa model lemah $h_t(x)$
	- $\alpha_t$: bobot model pada iterasi $t$
$$
F(x)=\sum^{T}_{t=1}\alpha_t\times h_t(x)
$$
- Alur dan Formulasi Proses Boosting
	1. Inisialisasi bobot awal $w_i=\frac{1}{n}$
	2. Melatih model lemah $h_t(x)$ pada setiap iterasi $t$
	3. Hitung error model $t$: $Error_t = \sum^{n}_{i=1}w_i\times 1(y_i \neq h_t(x_1))$. $1(y_i\neq h_t(x))$ adalah indikator yang bernilai $1$ jika $true$ dan sebaliknya
	4. Tentukan bobot model $\alpha_t=\frac{1}{2}\times\ln(\frac{1-Error_t}{Error_t})$
	5. Update bobot sample $w_i\leftarrow w_i\times\exp(-\alpha_t\times y_i \times h_t(x_i))$
	6. Gabungkan model $F(x)=\sum^{T}_{t=1}\alpha_t\times h_t(x)$
- Contoh varian boosting
	- AdaBoost: menggunakan bobot untuk sampel salah prediksi
	- Gradient Boosting: meminimalkan kesalahan residu
	- XGBosot: implementasi gradient boosting yang dioptimalkan
# Stacking
- Teknik Ensemble - Stacking
- Melibatkan pelatihan beberapa model (level 1) dan hasilnya menjadi input ke model meta (level 2)
- Model meta biasanya melakukan kombinasi linear seperti regresi linear atau logistik
- Formulasi
	- $g$: model meta dan $f_i(x)$: model level ke-1
$$
\hat{y}=g(f_1(x),f_2(x),...,f_n(x))
$$
