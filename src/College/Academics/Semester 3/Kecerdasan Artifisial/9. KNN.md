# Deskripsi Klasifikasi
- Memerlukan data yang terdiri dari sekumpulan fitur, salah satu fitur harus berupa kelas/kategori
- Bertujuan memberi label data baru yang belum punya kelas
# Teknik Klasifikasi
- Instance based
- Decision tree based
- Rule based
- Neural Network
- Naive Bayes dan Bayesian Network
- Support Vector Machine
# Instance-based Classifier
- Membandingkan data uji dengan data latih secara langsung
- Kelas data uji = kelas data latih yang paling mirip
- Metode
	- Rote learner (sama persis)
		- Akan gagal pada data uji yang tidak sama persis dengan data latih
	- Nearest neighbor (paling mirip)
		- Sangat sensitif terhadap noise
		- Kesalahan pemberian label pada data latih menyebabkan kesalahan klasifikasi pada data uji
		- Solusinya jangan hanya satu data namun gunakan beberapa
# K-Nearest Neighbor
- Komponen
	- Kumpulan data latih
	- Ukuran jarak untuk menghitung jarak antar data
	- Nilai berapa banyak tetangga yang akan diambil
- Cara kerja
	- Hitung jarak data uji ke setiap data latih
	- Ambil k data latih yang paling dekat
	- Tentukan kelas data uji menggunakan mayoritas kelas data latih
# Ukuran Jarak
- Digunakan untuk mengetahui kemiripan antara dua data
- Semakin kecil jarak semakin mirip
## Manhattan/City block distance
- Berdasarkan panjang total dari proyeksi garis menghubungkan kedua vektor pada masing-masing axis
$$
d=\sum^n_i|x_i-y_i|
$$
## Euclidean Distance
- Berdasarkan panjang dari garis lurus yang menghubungkan kedua vektor
- Perhitungan menggunakan akar dari jumlah kuadrat selisih kedua vektor
$$
d=\sqrt{\sum^n_i(x_i-y_i)^2}
$$
## Minkowski Distance
- Bentuk umum dari fungsi jarak dua vektor
$$
d=(\sum^n_{i=1}|x_i-y_i|^p)^\frac{1}{p}
$$
- Jika $p=1$ nilainya sama dengan Manhattan/city block distance
- Jika $p=2$ nilainya sama dengan Euclidean Distance
# Permasalahan KNN
- Berapa nilai $k$ yang tepat?
	- Jika terlalu kecil, sensitif terhadap noise/outlier
	- Jika terlalu besar, dapat dipengaruhi oleh data dari kelas yang berbeda
- Kompleksitas tinggi
	- Perhitungan jarak dilakukan terhadap setiap data latih
	- Semakin banyak data latih, semakin lama prosesnya
- Lazy learner
	- Proses belajar selalu dilakukan untuk setiap data uji
	- Sebenarnya tidak ada proses traning (???)
