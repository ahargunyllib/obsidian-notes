# Definisi
- Teknik yang memungkinkan komputer untuk "belajar" dari data, tanpa harus diprogram secara eksplisit
- Pemrograman Tradisional: Aturan + Data -> Pemrograman Tradisional -> Jawaban
- Pemrograman Mesin: Jawaban + Data -> Pemrograman Mesin -> Aturan
# Tahapan Pembelajaran
1. Penyimpanan data: menyimpan data yang akan dipelajari 
2. Abstraksi: proses pengubahan data menjadi representasi dan konsep yang lebih luas
3. Generalisasi: mengubah representasi data menjadi pengetahuan
4. Evaluasi: proses pengukuran proses pembelajaran
# Pembelajaran Tradisional vs Pembelajaran Mesin

| Aspek            | Manusia                               | Komputer                                             |
| ---------------- | ------------------------------------- | ---------------------------------------------------- |
| Penyimpanan data | Otak                                  | Harddisk, CPU, RAM                                   |
| Bentuk Abstraksi | Hubungan pada neuron otak             | Persamaan matematika, aturan, tree, graph, cluster   |
| Generalisasi     | Tidak dapat dipindahkan antar manusia | Dapat dipindahkan antar komputer (transfer learning) |

# Metode-metode Pembelajaran Mesin

## Supervised Learning
- Berdasarkan contoh yang sudah diberi label atau kategori
- Model pembelajaran menggunakan "guru"
## Unsupervised Learning: 
- Tanpa contoh/pembelajaran mandiri
- Digunakan dalam proses pengelompokan data
## Reinforcement Learning
- Dengan bantuan yang terbatas, berupa hadiah atau hukuman
# Tipe Pembelajaran Mesin
## Klasifikasi
- Proses prediksi label/kelas pada sebuah data
- Kelas/label adalah sekumpulan kategori yang nilainya sudah ditentukan
- Dengan "mempelajari" sekumpulan data yang telah diketahui kelasnya, datanya disebut data latih
- Bertujuan untuk melabeli data baru yang belum ada kelasnya, datanya disebut data uji
- Contoh dari supervised learning
## Regresi
- Mirip dengan klasifikasi, namun labelnya berupa angka (bukan kategori)
- Bertujuan untuk memperkirakan nilai suatu variabel pada data
- Contoh dari supervised leaning
## Clustering
- Tidak memerlukan label pada data latih
- Bertujuan untuk mengelompokkan data
- Data yang mirip akan dikelompokkan pada cluster yang sama
